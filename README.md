# KelanaAI

KelanaAI adalah aplikasi sederhana berbasis Python untuk membuat ringkasan perjalanan.

## Features

- Input destination
- Input country
- Input number of days
- Input travel budget
- Input currency
- Input travel month
- Generate trip summary
